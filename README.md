# Linux Automation using Bash Scripting

## Project Overview
This project automates common Linux system administration tasks using Bash scripting. It helps reduce manual effort by performing health checks, log cleanup, and service monitoring.

## Features
- Automated disk usage and memory checks
- Generated system health reports
- Cleaned old log files automatically
- Monitored running status of critical services
- Combined all tasks into a single executable Bash script

## Tech Stack
- Linux
- Bash Scripting
- Cron

## Project Structure
```bash
linux-automation-bash/
├── scripts/
│   ├── health_check.sh
│   ├── log_cleanup.sh
│   ├── service_monitor.sh
│   └── main.sh
├── logs/
├── reports/
└── README.md

```
How to Run
```
chmod +x scripts/*.sh
cd scripts
./main.sh
```
